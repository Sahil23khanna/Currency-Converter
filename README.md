# Currency Converter

A modern, responsive web application for real-time currency conversion. Convert between 70+ currencies with live exchange rates, featuring a beautiful gradient UI, currency swap functionality, and intelligent caching for optimal performance.

## Features

- 💱 **70+ Currencies** - Support for major and regional currencies worldwide
- 🔄 **Real-time Exchange Rates** - Live rates from exchangerate-api.com
- ⚡ **Smart Caching** - 1-minute cache to reduce API calls
- 🔀 **Quick Swap** - One-click currency swap button
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- 🎨 **Modern UI** - Beautiful gradient design with smooth animations
- ✨ **Smart Formatting** - Automatic currency formatting with proper decimal handling
- ⚠️ **Error Handling** - User-friendly error messages and validation

## Tech Stack

- HTML5
- CSS3 (with animations and responsive design)
- Vanilla JavaScript (ES6+)
- ExchangeRate-API (free, no API key required)

## Usage

Simply open `index.html` in your web browser. No build process or dependencies required!

## How It Works

1. Enter the amount you want to convert
2. Select the source currency (From)
3. Select the target currency (To)
4. Click "Convert" or press Enter
5. View the converted amount and exchange rate

Use the swap button (↕️) to quickly exchange the source and target currencies.
